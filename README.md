# 🏔️ Explore El Calafate

Página informativa de **asesoría gratuita para turistas** que quieren viajar a El Calafate y a la Patagonia. Reúne lo esencial para planificar el viaje: qué ver, qué comer, qué excursiones hacer y cómo organizar los días, con opción de dejar consultas.

## Características

- Guía de atracciones principales: **Glaciar Perito Moreno**, **Glaciar Spegazzini**, gastronomía calafateña, el pueblo de El Calafate y **El Chaltén**.
- Servicios adicionales de asesoría para organizar el viaje.
- Formulario para dejar consultas o compartir experiencias.
- Contenido claro y pensado para quien visita la Patagonia por primera vez.
- Responsive: se puede consultar desde el celular en el viaje.
